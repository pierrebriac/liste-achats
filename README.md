# Liste des choses à acheter encore

Petite page à partager : le matériel qu’il reste à acheter pour la traversée du Canada à vélo.

- Page publiée par GitHub Pages : https://pierrebriac.github.io/liste-achats/
- La liste elle-même est gardée par le service Cloudflare du projet `traversee-canada` (`/api/achats`) ; cette page l’affiche et envoie les ajouts et suppressions.
- Ajouter ou supprimer un article demande le mot de passe de la liste.
